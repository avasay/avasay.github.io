Create a Web API using InMemory Database in ASP.NET Core

Alejandrio VasayNovember 15, 2019

When you are developing an application, you may want to test your application without connecting to a real database. This is where the in-memory database comes in. In-memory database is a database that is stored in memory instead of being stored on disk. This means that the data is lost when the application is closed. In-memory database is useful for testing and prototyping purposes.

How to use In-Memory Database in ASP.NET Core

ASP.NET Core provides in-memory database support through the Entity Framework Core. To use in-memory database in ASP.NET Core, you need to add the following NuGet package to your project:

For this demo, I will create a simple Employee database. I will create an ASP.NET Core Web API project in Visual Studio Community(2019). And I will test three services: GET, GET{by id}, and POST. The first GET/ service gets all employees, GET/{id} get an employee by Id, and POST/ creates an employee.

I’m using a browser-based REST client plugin for Chrome to test my API — called Boomerang. There are dozens of REST client plugins for various browsers, but this is the best plugin to me and the easiest. You also use your own client to test this.
